   Book management system consists of various features; from security, book management, 
   archiving a book, sharing and even updating a book.
 
  This application simulates various aspects of development and how to bring to life 
  a full stack application with spring boot the `smart configuration || autoconfiguration`.
   
  The primary tech stacks are Spring boot and angular, swagger,`(open api spec)`,docker for 
  spinning up postgres and mail dev containers. 

  ### steps to running the project
****************************************

➤ **Install jdk and configure the PATH.**  
➤ **Install jdk and configure the PATH.**  
➤ **Install docker and use docker compose up to power up the docker compose file.**  
➤ **Use spring-boot:run command in root directory of book-network to start backend services**
➤ **Use ngserve command in root directory of book-network-ui to start frontend**
